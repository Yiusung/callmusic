技术原理

音频信号路径

本地音乐文件
→
AVAudioPlayerNode
→
AVAudioEngine
→
VoiceProcessingIO
AudioUnit
→
通话音频流
→
对方听到 ✅

关键：将 AVAudioSession.mode 设置为 .voiceChat， 系统会激活 kAudioUnitSubType_VoiceProcessingIO——这正是系统通话所使用的底层 AudioUnit。 此模式下 AVAudioEngine 的输出自然路由到通话音频流中。


麦克风静音原理

真实麦克风输入
→
inputNode.installTap
→
缓冲清零（全0数据）
→
通话流：静音 ✅

安装麦克风 tap 后，静音状态下将实时缓冲数据全部置零，使对方听到的是静音而非真实麦克风声音。

安装到 iPhone（详细步骤）

ℹ️

需要一台 Mac + Xcode 15+。iOS 设备用 USB 连接，使用免费 Apple ID 即可完成签名安装，无需付费开发者账号。

  1. 复制项目到 Mac

    将整个 CallMusicPlayer/ 文件夹传输到 Mac，双击 CallMusicPlayer.xcodeproj 打开 Xcode。

  2. 配置签名团队

    点击左侧项目导航中的根节点 → TARGETS → CallMusicPlayer → Signing & Capabilities
    Team 选择你自己的 Apple ID，Bundle Identifier 改为唯一值，例如：com.yourname.callmusicplayer

  3. 添加后台权限 Capability（关键！）

    在 Signing & Capabilities 页面，点击 + Capability，搜索并添加 Background Modes，然后勾选：
    ✅ Audio, AirPlay, and Picture in Picture
    ✅ Voice over IP

  4. 连接 iPhone 并安装

    iPhone 通过 USB 连接 Mac，在 Xcode 顶部 scheme 选择你的设备，按 ⌘R 编译并安装。

  5. 信任开发者证书

    手机端：设置 → 通用 → VPN与设备管理 → 找到你的 Apple ID → 点击信任。

  6. 授权麦克风

    首次启动 App 时点击允许麦克风权限弹窗。这是静音功能正常工作的必要条件。

注意事项

⚠️

仅供个人测试：本应用使用了 voiceChat 模式注入通话音频流，Apple 不允许此类应用上架 App Store，仅可在自己的设备上通过 Development 签名安装使用。

项目说明
适用电话类型系统 PSTN 来电（运营商电话）。微信/FaceTime 通话有自己独立的音频会话，不受本 App 控制。
主动拨出本版本监听 callConnected 事件，拨出接通同样会触发播放。
音质voiceChat 模式会开启 AEC（回声消除）和降噪处理，可能会轻微压缩音乐音质，这是系统限制，无法绕过。
App 需保持活跃来电接通时 App 必须在前台或后台运行（已开启后台音频模式）。若被系统彻底挂起则不会触发。
证书有效期免费 Apple ID 签名有效期 7 天，到期后重新用 Xcode 安装即可续期。
测试建议先用另一部手机拨打到被测试机，验证对方是否能听到音乐。

常见问题

对方听不到音乐怎么办？

1. 确认 后台模式 Capability 中 Audio 和 Voice over IP 已勾选（最常见原因）

2. 确认来电接通时 App 正在运行，未被系统挂起

3. 通话接通后等 1-2 秒，让系统音频会话切换完成

4. 重启 App，重新选择音乐文件

如何选择语音备忘录？

打开「文件」App → 「浏览」→「iCloud Drive」→「语音备忘录」，即可看到所有录音文件（.m4a 格式）。

或者在「语音备忘录」App 中，长按某条录音 → 「共享」→「存储到文件」，先保存到本地，再在 App 中选择。

App 崩溃或引擎无法启动？

1. 检查麦克风权限：「设置」→ 隐私与安全性 → 麦克风 → 找到本 App 并开启

2. 强制关闭 App 后重新启动

3. Xcode 控制台中查看 [AudioMixEngine] 开头的日志了解详细原因

能否支持微信/FaceTime 通话？

不支持。微信、FaceTime、WhatsApp 等应用使用自己独立的 AVAudioSession（通常是 VoIP 分类），会抢占或隔离音频会话，导致本 App 的 voiceChat 模式无效。这是 iOS 沙盒限制，无法跨 App 注入音频。

免费 Apple ID 和付费开发者账号有什么区别？

免费账号：签名证书 7 天有效期，到期后需要重新用 Xcode 安装；每个设备最多安装 3 个 App；无需付费，测试用完全够用。

付费开发者账号（$99/年）：证书有效期 1 年，支持 TestFlight 分发给他人，可上架 App Store。
